# PostgreSQL-скрипты

Файлы выполняются в следующем порядке:

| Файл | Назначение |
| --- | --- |
| `01_schema.sql` | Создаёт схему, таблицы, ключи и ограничения. |
| `02_seed_data.sql` | Добавляет безопасные синтетические демо‑данные. |
| `03_indexes.sql` | Добавляет индексы для поиска, связей и отчётов. |
| `04_views.sql` | Создаёт представления для каталога, договоров, платежей и очереди техподдержки. |
| `05_functions.sql` | Добавляет функции для описания оборудования, расчётов и проверки мощности. |
| `06_procedures.sql` | Добавляет процедуры для заявок, платежей и назначения задач. |
| `07_roles_permissions.sql` | Создаёт роли БД и выдаёт права доступа. |
| `08_demo_queries.sql` | Содержит демонстрационные `SELECT`‑запросы для проверки. |

При запуске через Docker Compose эти файлы применяются автоматически при первой инициализации базы данных.
